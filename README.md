🎯 C++ Quiz Application

📌 About Project

This is a simple Quiz Application developed using C++.
It allows users to answer multiple-choice questions and calculates their final score.

✨ Features

- 5 Multiple Choice Questions
- 4 Options for Each Question
- Automatic Score Calculation
- Displays Final Score
- Pass or Fail Result

🛠️ Technologies Used

- C++
- If-Else Statements
- Variables
- Input and Output

▶️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Compile the C++ file.
4. Run the program.
5. Answer all the quiz questions.

- User Input
- Score Calculation
- Basic Programming Logic
